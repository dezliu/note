#### v-cloak

**如果网比较慢 {{msg}}会现在页面上显示，等数据加载到后再替换，可能会有页面闪烁的问题, 使用v-cloak可以解决此问题。**

```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Document</title>
    <script src="./lib/vue.js"></script>
    <style>
        [v-cloak] {
            display: none;
        }
    </style>
</head>
<body>
    <div id="app">
        <p v-cloak>{{msg}}</p>
    </div>
    
    <script>
        var vm = new Vue({
            el: '#app',
            data: {
                msg: '123'
            }
        });
    </script>
</body>
</html>

```

#### v-text

**v-text默认没有闪烁问题，但是v-text会覆盖标签中的内容**

```
<div id="app">
    <h4 v-text="msg"></h4>
    <!-- 默认v-text 是没有闪烁问题的 -->
    <!-- v-text 会覆盖元素中原本的内容，但是插值表达式指挥替换自己的占位符，不会把整个元素的内容清空 -->
</div>

```

#### v-html

**如果变量中是html标签，使用v-text或 {{}}会被转义输出, v-htmltong**

```
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>Document</title>
    <script src="./lib/vue.js"></script>
</head>
<body>
    <div id="app">
        <div>{{msg1}}</div>
        <div v-text="msg1"></div>
        <div v-html="msg1"></div>
    </div>
    
    <script>
        var vm = new Vue({
            el: '#app',
            data: {
                msg: '123',
                msg1: '<h1>I\'m a big h1 flag!!!</h1>'
            }
        });
    </script>
</body>
</html>

```
