# 8.指令-使用钩子函数的第二个binding参数拿到传递到值

- 笔记本：02.品牌案例
- 创建时间：2019-12-16 09:31:42 UTC
- 更新时间：2019-12-16 09:56:15 UTC
- 印象笔记 GUID：e345fda9-d988-4639-a0de-d3e31d308e2f

```
<input type="text" class="form-control" v-model="keywords" v-focus v-color="'blue'">

<div id="app2">
    <h3 v-color="'pink'">{{ date | dateFormat }}</h3>
</div>

<script>
    // 自定义一个设置字体颜色的指令
    Vue.directive('color', {
        // 样式只要通过指令绑定给了元素，不管这个元素有没有被插入到页面中去，这个元素肯定有了一个内敛的样式，将来元素肯定会显示到页面，这时候浏览器的渲染引擎必然会解析样式，应用给这个元素
        bind: function(el, binding) {
            // el.style.color="red";
            // 和样式相关的操作，一般都可以在bind 执行
            el.style.color = binding.value;
        }
    });
</script>

```
