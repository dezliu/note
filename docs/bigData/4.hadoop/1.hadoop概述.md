##### 集群

- 分布式运行

- 计算和数据在一起

##### Hadoop

**Hadoop的思想之源：Google(第一个遇到大量数据计算的公司)**

- OpenStacck: NASA

- 面对的数据和计算难题

  - 大量的网页怎么存储

  - 搜索算法(倒排索引的思想)

- 带给我们的关键技术和思想(Google三大理论)

  - GFS (Google File System)

  - Map-Reduce

  - Bigtable

**Hadoop创始人：**
 Hadoop作者Doug cutting，就职yahoo期间开发了Hadoop项目(之前已经开始实施)，目前在Cloudera公司从事架构工作

Hadoop模块：

- Hadoop Common: 提供对大数据模块支持的工具包

- Hadoop Distributed File System(HDFS): Hadoop 分布式文件系统

- Hadoop YARN: 框架，规划集群资源管理

- Hadoop MapReduce: 基于YARN资源管理的大数据集合并行处理的计算框架

Spark：基于内存迭代的大数据框架 （快）
 Zookeeper: 分布式的协调系统（负责协调其他大数据集群的健康和运行状态）
