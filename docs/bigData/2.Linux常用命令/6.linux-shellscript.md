```
echo $$                             # 输出当前人机交互的bash进程号
ps -ef

```

```
vim test.txt
echo "hello world"
ls -l /
echo $$
source test.txt
. test.txt
# . 和 source是一个功能两种写法
pstree                                              # 查看进程树
/bin/bash                                        # 启动一个bash
/bin/bash test.txt                            # 启动时读取文件，然后退出回到父进程
vim test.txt
#!/bin/bash
echo "hello world"
ls -l / echo $$
chmod u+x test.txt
./test.txt

```

**脚本本质：**

- #!/bin/bash

- #!/usr/bin/python

**读取方式：**

- 当前shell: source/.

- 新建子shell: /bin/bash file / ./file.sh(chmod u+x file.sh)

***函数***

```
abc() {
    echo "hello world"
    echo $$
}
abc
type abc
# abc is a function

```

- 若当前shell执行，若命令有问题，当前进程就挂了，如果扔到子进程执行，有bug，最多子进程挂掉，回到父进程依然可以操作。
