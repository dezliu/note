**linux文件树结构**

- /bin和/sbin 一般放可执行程序

- /etc 放配置文件 /lib和/lib64 放扩展库(库文件)

- /boot 引导目录

- /dev 设备抽象成文件在此目录下

- /home 普通用户的家目录

- /root root用户的家目录

- /usr 通过向导安装的软件(npm...)。

- /var 程序运行时产生的数据(eg:日志)一般生成文件放在此

- /opt 我们自己维护，一般自己编译的软件放在此

**FileSystem HHierarchy Standard(文件系统层次化标准)**

- /boot:系统启动相关的文件，如内核、initrd，以及grub(bootloader)

- /dev:设备文件

- /etc:配置文件

- /home:用户的家目录，每一个用户的家目录通常默认为/home/USERNAME

- /root:管理员的家目录

- /lib:库文件

- /media:挂载点目录，移动设备

- /mnt:挂载点目录，额外的临时文件系统

- /opt:可选目录，第三方程序的安装目录

- /proc:伪文件系统，内核映射文件

- /sys:伪文件系统，跟硬件设备相关的属性映射文件

- /tmp:临时文件, /uar/tmp

- /var:可变化的文件

- /bin:可执行文件，用户命令

- /sbin:管理命令

**vim**

打开文件：
 vim +#: 打开文件，并定位于第#行 # eg: vim +22 a.txt
 vim +: 打开文件，定位至最后一行 # eg: vim + a.txt
 vim +PATTERN:打开文件，定位至第一次被PATTERN匹配到的行的行首
 关闭文件：eg: vim +/liudezhi a.txt
 ZZ: 保存并退出，不需要冒号，编辑模式
 翻屏
 ctrL: f,b
 u 撤销
 ctrl +r 重做， 撤销的操作
 . 重复上一步的操作
 查找
 :/liudezhi 定位到行开始
 /liudezhi 定位到查询的字符串
 删除
 :1,d 删除第一行到最后一行U(代表最后一行) 或则:%d
 :4, $-1d 删除第4行到倒数第2行

***末行模式***

- s查找并替换
 - s/str1/str2/gi
 /: 临近s命令的第一个字符为边界字符：/, @, #
 g: 一行内全部替换
 i: 忽略大小写
 - 范围
 n: 行号
 .: 当前光标行
 +n: 偏移n行
 $: 末尾n行
 %: 全文
