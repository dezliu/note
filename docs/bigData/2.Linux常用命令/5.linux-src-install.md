**编译安装**

- 配置文件: Makefile

- 编译，安装命令: make
 eg: 编译安装nginx

  - tar xf解压


 rpm安装：

- ivh filename

- --prefix

 rpm升级：

- -Uvh

- -Fvh

 rpm卸载：

- -e PACKAGE_NAME

rpm查询

- rmp -qa: 查询已经安装的所有包

- rpm -q PACKAGE_NAME: 查询指定的包是否已经安装

- rpm -qi PACKAGE_NAME: 查询指定包的说明信息

- rpm -ql PACKAGE_NAME: 查询指定包安装后生成的文件列表

- rpm -qc PACKAGE_NAME: 查询指定包安装的配置文件

- rpm -qd PACKAGE_NAME: 查询指定包安装的帮助文件

- rpm -q --scripts PACKAGE_NAME: 查询指定包中包含的交本

- rpm -qf /path/to/somefile: 查询文件是由哪个rpm包安装生成的

- 如果某rpm包尚未安装，需查询其说明信息、安装以后会生成的文件

  - rpm -qpi /PATH/TO/PACKAGE_FILE

  - rpm -qpl

```
rpm -iv jdk-8u231-linux-x64.rpm
rpm -qa
# 查询所有rpm安装的软件
rpm -qa | grep jdk
# 查询出的是包的名称
rpm -ql jdk1.8-1.8.0_231-fcs.x86_64
rpm -ql jdk1.8-1.8.0_231-fcs.x86_64 | more
whereis java
# 查询java命令位置
ls -l /usr/bin/java
lrwxrwxrwx 1 root root 22 Nov 22 21:05 /usr/bin/java -> /etc/alternatives/java
# 是一个链接，连接到安装的java
# 但是这样只可以用已经链接的，其他的还是要配置 path
vim /etc/profile
export JAVA_HOME=/usr/java/jdk...
export PATH=$PATH:$JAVA_HOME/bin
:wq
source /etc/profile

```

**yum安装：仓库**
 yum只是用仓库机制，它底层装的东西安装形式还是rpm，可以说yum仓库是对rpm的封装，让rpm安装更容易一些。
 yum安装： 类似 C/S

- 基于rpm包管理

- 提供rpm仓库

repo:

- /etc/yum.repos.d/

- [repoID]

- baseurl=
 http://
 file://
 ftp://

- gpgcheck=1/0

- enable=0/1
 仓库中包含两类数据，一类是所有的rpm包，一类是包的元数据描述文件

```
yum repolist

```

**使用本机，自己为自己提供仓库**
 首先给系统在vm上挂载系统光盘（完整版）

```
cd /etc/yum.repos.d
mv C* ./backup
cp ./backup/CentOS.Base.repo ./
vim CentOs.Base.repo
[ooxx] name=CentOS-$releasever - Base-liudezhi - mirrorrs.aliyun.com
baseurl=file:///mnt gpgcheck=0
yum clean all
yum makecache
# 演示，先删除man
yum remove man
yum repolist
# ls -l /mnt/Packages/ | wc -l 结果是3242
# yum repolist 结果是6706，是因为还有一部分包在第二张光盘上

```
