- 网络配置
 编辑 ifcfg-eth0文件(/etc/sysconfig/network-scripts)

```
#HWADDR=00:0C:29:54:B6:9A       #注释，方便后期复制
#BOOTPROTO=dhcp                      #修改
BOOTPROTO=static

```

#点击Vmware 编辑 -> 虚拟网络编辑器,选择NAT模式的网络，查看左下角子网IP
 #eg:192.168.231.0，注意231.0是网络号，不要配置给某个主机，231.255是广播地址也不是给某个主机用的
 #可用地址范围 192.168.231.1 ~ 192.168.231.254
 #192.168.231.1作为windows上虚拟网卡的地址，2作为网络的网关，可用地址是3~254这个范围。
 #点击NET设置，可以查看网关IP

```
#在ifcfg-eth0文件后添加
IPADDR=192.168.231.3               #IP地址，可用范围(3~254)
NETMASK=255.255.255.0           #掩码
GATEWAY=192.168.231.2           #网关 DNS1=114.114.114.114#DNS

```

重新加载网路配置

```
service network restart

```

此时网络配置完成，即可联网。
 此时模板即创建完成，后期的虚拟机通过此虚拟机克隆即可。

**补充**
 windows 服务：
 VMware DHCP Service
 VMware NAT Service
 VMware Workstation Service

- 关闭防火墙

```
service iptables stop                     #只是关闭，没有禁用防火墙，下次开机防火墙依旧会打开
chkconfig                                   #罗列出linux开机有哪些服务会运行/关闭
#3:。。。。3代表命令行模式
chkconfig iptables off                  #禁用防火墙

```

- 关闭selinux

```
cd /etc/selinux vi config #将SELINUX=enforcing修改未disabled SELINUX=disable

```

开机重启自动生效(负责安全方面的东西)

```
cat /etc/udev/rules.d/70-persistent-net.rules               #eth0和硬件地址关系绑定

```

删除模板系统的此软件可以保证克隆出来的机器eth0是可用的

```
rm -f /etc/udev/rules.d/70-persistent-net.rules

```

删除后关机

```
poweroff

```
