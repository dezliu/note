#### 1. elasticsearch 了解多少，说说你们公司 es 的集群架构，索引数据大小，分片有多少，以及一些调优手段。

**设计阶段调优**
 1、根据业务增量需求，采取基于日期模板创建索引，通过 roll over API 滚动索引;
 2、使用别名进行索引管理;
 3、每天凌晨定时对索引做 force_merge 操作，以释放空间;
