### Java8 新特性简介

- 速度更快
 eg：HashMap Java8之前，底层是基于**哈希算法+数组+链表**的方式，如果数据过多，就会导致一个链表过长，当一个新元素进入时，可能需要对整个链表进行碰撞。
 Java8 采用了**哈希算法+数组+链表+红黑树**的方式。当碰撞元素个数大于8并且总元素大于64.就会转换为红黑树结构。使用红黑树结构后，除了添加，其他的效率都变高了。

>
https://blog.csdn.net/weixin_44460333/article/details/86770169

- 代码更少（增加了新的语法 Lambda 表达式）

- 强大的 Stream API

- 便于并行

- 最大化减少空指针异常 Optional
