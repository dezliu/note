## 新时间日期 API

### 1. 传统时间格式化的线程安全问题

```
public static void main1(String[] args) throws ExecutionException, InterruptedException {
        SimpleDateFormat sdf = new SimpleDateFormat("yyyyMMdd");

        Callable<Date> task = () -> sdf.parse("20161218");

        ExecutorService pool = Executors.newFixedThreadPool(10);

        List<Future<Date>> results = new ArrayList<>();

        for (int i = 0; i < 10; i++) {
            results.add(pool.submit(task));
        }

        for (Future<Date> future : results) {
            System.out.println(future.get());   // 抛出异常，存在线程安全问题
        }

        pool.shutdown();
    }

```

**解决方法（Java8 之前）：**

```
public class DateFormatThreadLocal {

    private static final ThreadLocal<DateFormat> df = new ThreadLocal<DateFormat>() {
        @Override
        protected DateFormat initialValue() {
            return new SimpleDateFormat("yyyyMMdd");
        }
    };

    public static Date convert(String source) throws ParseException {
        return df.get().parse(source);
    }
}

```

```
public static void main1(String[] args) throws ExecutionException, InterruptedException {
        Callable<Date> task = () -> DateFormatThreadLocal.convert("20210225");

        ExecutorService pool = Executors.newFixedThreadPool(10);

        List<Future<Date>> results = new ArrayList<>();

        for (int i = 0; i < 10; i++) {
            results.add(pool.submit(task));
        }

        for (Future<Date> future : results) {
            System.out.println(future.get());
        }

        pool.shutdown();
    }

```

**Java8 后：** 线程安全

```
public static void main(String[] args) throws ExecutionException, InterruptedException {
        DateTimeFormatter dtf = DateTimeFormatter.ofPattern("yyyyMMdd");
        Callable<LocalDate> task = () -> LocalDate.parse("20210225", dtf);

        ExecutorService pool = Executors.newFixedThreadPool(10);

        List<Future<LocalDate>> results = new ArrayList<>();

        for (int i = 0; i < 10; i++) {
            results.add(pool.submit(task));
        }

        for (Future<LocalDate> future : results) {
            System.out.println(future.get());
        }

        pool.shutdown();
    }

```

### 2. Java8 时间类

#### 2.1. 使用 LocalDate、LocalTime、LocalDateTime

LocalDate、LocalTime、LocalDateTime 类的实例是**不可变的对象**，分别表示使用 ISO-8601日历系统的日期、时间、日期和时间。它们提供了简单的日期或时间，并不包含当前的时间信息。也不包含与时区相关的信息。

**注:** ISO-8601日历系统是国际标准化组织制定的现代公民的日期和时间的表示法

 | 方法 | 描述 | 示例
 | now() | 静态方法，根据当前时间创建对象 | `LocalDate localDate = LocalDate.now();` `LocalTime localTime = LocalTime.now();` `LocalDateTime localDateTime = LocalDateTime.now();`
 | of() | 静态方法，根据指定日期/时间创建对象 | `LocalDate localDate = LocalDate.of(2016, 10, 26);` `LocalTime localTime = LocalTime.of(02, 22, 56);` `LocalDateTime localDateTime = LocalDateTime.of(2016, 10, 26, 12, 10, 55);`
 | plusDays, plusWeeks, plusMonths, plusYears | 向当前 LocalDate 对象添加几天、几周、几个月、几年 |
 | minusDays, minusWeeks, minusMonths, minusYears | 从当前 LocalDate 对象减去几天、几周、几个月、几年 |
 | plus, minus | 添加或减少一个 Duration 或 Period |
 | withDayOfMonth, withDayOfYear, withMonth, withYear | 将月份天数、年份天数、月份、年份修改为指定的值并返回新的 LocalDate 对象 |
 | getDayOfMonth | 获得月份天数(1-31) |
 | getDayOfYear | 获得年份天数(1-366) |
 | getDayOfWeek | 获得星期几(返回一个 DayOfWeek 枚举值) |
 | getMonth | 获得月份, 返回一个 Month 枚举值 |
 | getMonthValue | 获得月份(1-12) |
 | getYear | 获得年份 |
 | until | 获得两个日期之间的 Period 对象，或者指定 ChronoUnits 的数字 |
 | isBefore, isAfter | 比较两个 LocalDate |
 | isLeapYear | 判断是否是闰年 |

**eg**

```
// 1. LocalDate LocalTime LocalDateTime 三个类的使用方式是一样的（方便人阅读）
@Test
public void test1() {
    LocalDateTime ldt = LocalDateTime.now();    // 获取实例
    System.out.println(ldt);

    LocalDateTime ldt2 = LocalDateTime.of(2020, 02, 21, 01, 23, 20); // 指定年月日时分秒获取实例
    System.out.println(ldt2);

    LocalDateTime ldt3 = ldt.plusYears(2);  // 年 + 2，注意：每次运算都会产生一个新实例
    System.out.println(ldt3);

    LocalDateTime ldt4 = ldt.minusMonths(2);
    System.out.println(ldt4);

    System.out.println(ldt.getYear() + "年" + ldt.getMonthValue() + "月" + ldt.getDayOfMonth() + "日" +
            ldt.getHour() + "时" + ldt.getMinute() + "分" + ldt.getSecond() + "秒");
}

```

#### 2.2. Instant 时间戳

用于“时间戳”的运算。它是以Unix元年(传统的设定为UTC时区1970年1月1日午夜时分)开始所经历的毫秒数进行运算
 **eg：**

```
// 2. Instance（以 Unix 元年：1970年1月1日00:00:00 到某个时间之间的毫秒值）
@Test
public void test2() {
    Instant ins1 = Instant.now();   // 获取实例，默认获取 UTC 时区（世界协调时间）
    System.out.println(ins1);   // 2021-01-24T17:16:40.617Z

    OffsetDateTime odt = ins1.atOffset(ZoneOffset.ofHours(8));
    System.out.println(odt);    // 2021-01-25T01:16:40.617+08:00

    System.out.println(ins1.toEpochMilli());    // 转为时间戳（毫秒值）

    Instant ins2 = Instant.ofEpochSecond(60);   // 相较于 Unix 元年计算
    System.out.println(ins2);   // 1970-01-01T00:01:00Z
}

```

#### 2.3. Duration 和 Period

- Duration:用于计算两个“时间”间隔

- Period:用于计算两个“日期”间隔
 **eg：**

```
// 3.1. Duration：计算两个"时间"之间的间隔；
@Test
public void test31() {
    Instant ins1 = Instant.now();
    try {
        Thread.sleep(1000);
    } catch (Exception e) {
    }
    Instant ins2 = Instant.now();

    Duration between = Duration.between(ins1, ins2);
    System.out.println(between.getSeconds());   // 秒
    System.out.println(between.toMillis());     // 毫秒

    System.out.println("--------------------");

    LocalTime ld1 = LocalTime.now();
    try {
        Thread.sleep(1000);
    } catch (Exception e) {
    }
    LocalTime ld2 = LocalTime.now();
    System.out.println(Duration.between(ld1, ld2).toMillis());
}
// 3.2. Period：计算两个"日期"之间的间隔;
@Test
public void test32() {
    LocalDate ld1 = LocalDate.of(2020, 07, 07);
    LocalDate ld2 = LocalDate.now();

    Period between = Period.between(ld1, ld2);
    System.out.println(between.getYears() + "年" + between.getMonths() + "月" + between.getDays() + "日");
}

```

#### 2.4. 日期的操纵 - TemporalAdjuster

- TemporalAdjuster : 时间校正器。有时我们可能需要获取例如:将日期调整到“下个周日”等操作。

- TemporalAdjusters : 该类通过静态方法提供了大量的常用 TemporalAdjuster 的实现。

**eg：**

```
// TemporalAdjuster：时间矫正器
@Test
public void test4() {
    LocalDateTime ldt = LocalDateTime.now();
    System.out.println(ldt);

    LocalDateTime ldt2 = ldt.withDayOfMonth(10);    // 将日指定为指定日期
    System.out.println(ldt2);

    LocalDateTime ldt3 = ldt.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));    // 获取下一个周日
    System.out.println(ldt3);

    // 自定义：下一个工作日
    LocalDateTime ldt5 = ldt.with((d) -> {
        LocalDateTime ldt4 = (LocalDateTime) d;
        DayOfWeek dayOfWeek = ldt4.getDayOfWeek();
        if (dayOfWeek.equals(DayOfWeek.FRIDAY)) {
            return ldt4.plusDays(3);
        } else if (dayOfWeek.equals(DayOfWeek.SATURDAY)) {
            return ldt4.plusDays(2);
        } else {
            return ldt4.plusDays(1);
        }
    });
    System.out.println(ldt5);
}

```

#### 2.5. 解析与格式化 - DateTimeFormatter

java.time.format.DateTimeFormatter 类:该类提供了三种格式化方法:

- 预定义的标准格式

- 语言环境相关的格式

- 自定义的格式
 **eg：**

```
// DateTimeFormatter：格式化时间/日期
@Test
public void test5() {
    DateTimeFormatter isoDate = DateTimeFormatter.ISO_DATE; // 使用预定义的标准格式
    LocalDateTime ldt = LocalDateTime.now();

    String strDate = ldt.format(isoDate);
    System.out.println(strDate);

    System.out.println("--------------------");
    DateTimeFormatter dateTimeFormatter = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss");
    String strDate2 = dateTimeFormatter.format(ldt);    // 或 ldt.format(dateTimeFormatter); 都可以
    System.out.println(strDate2);

    LocalDateTime parse = LocalDateTime.parse(strDate2, dateTimeFormatter); // 字符串解析回日期
    System.out.println(parse);
}

```

#### 2.6. 时区的处理

Java8 中加入了对时区的支持，带时区的时间为分别为: ZonedDate、ZonedTime、ZonedDateTime
 其中每个时区都对应着 ID，地区ID都为“{区域}/{城市}”的格式 例如: Asia/Shanghai 等
 ZoneId:该类中包含了所有的时区信息
 getAvailableZoneIds() : 可以获取所有时区时区信息
 of(id) : 用指定的时区信息获取 ZoneId 对象
 **eg：**

```
// ZoneDate、ZoneTime、ZoneDateTime
@Test
public void test6() {
    LocalDateTime ldt = LocalDateTime.now(ZoneId.of("Asia/Shanghai"));  // 指定时区，构建时间
    System.out.println(ldt);

    ZonedDateTime zonedDateTime = LocalDateTime.now(ZoneId.of("Asia/Shanghai")).atZone(ZoneId.of("Asia/Shanghai"));   // 创建 LocalDateTime后指定时区
    System.out.println(zonedDateTime);
}
// ZoneId
@Test
public void test7() {
    Set<String> availableZoneIds = ZoneId.getAvailableZoneIds();    // 查看所有时区
    availableZoneIds.forEach(System.out::println);
}

```
