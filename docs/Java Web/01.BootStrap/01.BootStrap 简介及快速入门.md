# 01.BootStrap 简介及快速入门

- 笔记本：01.BootStrap
- 创建时间：2020-01-25 13:37:43 UTC
- 更新时间：2020-01-25 13:56:53 UTC
- 印象笔记 GUID：39e54f1f-589e-4a11-ad8f-a75c1f71a87d

**概念：** 一个前端开发的框架，Bootstrap，来自Twitter，是目前很受欢迎的前端框架，是基于HTML、CSS、Javascript 的，它简洁灵活，使得 Web 开发更加快捷

- 框架：一个半成品软件，开发人员可以在框架基础上，再进行开发，简化编码

- 好处：

  -

    1. 定义了很多的 css 样式和 js 插件。我们开发人员直接可以使用这些样式和插件得到丰富的页面效果

  -

    1. 响应式布局（同一套页面可以兼容不同分辨率的设备）。

**快速入门：**

1. 下载Bootstrap
 css
 fonts
 js

1. 在项目中将这三个文件夹复制

1. 创建html 页面，引入必要的资源
