#### IDEA与tomcat 的相关配置

1. IDEA 会为每一个tomcat 部署的项目单独建立一份配置文件

  - 查看控制台的log：Using CATALINA_BASE: "路径\system\tomcat..."

1. 工作空间项目和tomcat部署的web项目

  - tomcat 真正访问的时“tomcat部署的web项目”，“tomcat部署的web项目”对应着“工作空间项目”的web 目录下的所有资源

  - WEB-INF 目录的资源不能被浏览器直接访问。
