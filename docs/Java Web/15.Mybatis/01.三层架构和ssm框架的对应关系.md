1.
什么是框架
 它是我们软件开发中的一套解决方案，不同的框架解决的是不同的问题。

1.
使用该框架的好处：
 框架封装了很多细节，使开发者可以使用极简的方式实现功能。大大提高开发效率。

1.
三层架构

  - 表现层：是用于展示数据的

  - 业务层：是处理业务需求的

  - 持久层：是和数据库交互的

![attachment-1.png](01.三层架构和ssm框架的对应关系_assets/attachment-1.png)

1. 持久层解决方案
 JDBC 技术：
 Connection
 PreparedStatement
 ResultSet
 Spring 的JdbcTemplate：
 Sping 中对jdbc的简单封装
 Apache 的DBuilts：
 它和Spring 的JdbcTemplate 很像，也是对Jdbc 的简单封装
 以上这些都不是框架
 JDBC 是规范
 Spring 的JdbcTemplate 和Apache 的DBUtils 都只是工具类
