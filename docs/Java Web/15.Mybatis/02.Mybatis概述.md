# 02.Mybatis概述

- 笔记本：15.Mybatis
- 创建时间：2020-03-02 04:00:43 UTC
- 更新时间：2020-03-02 04:06:39 UTC
- 印象笔记 GUID：4c2623bd-5732-4c81-85cf-fcda2f581e31

mybatis 是一个优秀的java 的持久层框架，它内部封装了jdbc，使得开发者只需要关注sql 语句本身，而不需要花费精力去处理加载驱动、创建连接、创建statement 等繁杂的过程。
 它使用了ORM 思想实现了结果集的封装。

ORM：Object Relational Mapping 对象关系映射
 简单的说：就是把数据库表和实体类及实体类的属性对应起来
 让我们可以操作实体类就实现操作数据库表
