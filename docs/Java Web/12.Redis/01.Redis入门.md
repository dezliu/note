  1.
安装：

    1. windows：解压直接可以使用

      - redis.windows.conf：配置文件

      - redis-cli.exe：redis的客户端

      - redis-server.exe：redis的服务器端

    1. linux：

```
wget http://download.redis.io/releases/redis-5.0.4.tar.gz
tar xzf redis-5.0.4.tar.gz
cd redis-5.0.4
make

```

```
src/redis-server    # 启动服务端

```

```
src/redis-cli       # 启动客户端
set foo bar         # 添加数据
get foo             # 获取数据

```
