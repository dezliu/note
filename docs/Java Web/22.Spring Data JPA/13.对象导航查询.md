# 对象导航查询

查询一个对象的同时，通过此对象查询他的关联对象

## 1. 测试查询

**案例:** 客户和联系人

```
/**
 * 测试对象导航查询(查询一个对象的时候，通过此对象查询所有的关联对象)
 * error: no Session
 */
@Test
@Transactional  // 解决在 java 代码中的 no session 问题
public void testQuery() {
    // 查询 id 为1的客户
    Customer customer = customerDao.getOne(4l);
    // 对象导航查询，此客户下的所有联系人
    Set<LinkMan> linkMans = customer.getLinkMans();
    for (LinkMan linkMan : linkMans) {
        System.out.println(linkMan);
    }
}

```

## 2. 延迟加载

### 2.1. 从一方查询多方

```
/**
 * 对象导航查询：
 *  默认使用的是延迟加载的形式查询的
 *      调用 get 方法并不会立即发送查询，而是在使用关联对象的时候才会去查询
 * 修改配置，将延迟加载改为立即加载
 *  fetch，需要配置到多表映射关系的注解上
 */
@Test
@Transactional
public void testQuery2() {
    // 查询 id 为1的客户
    Customer customer = customerDao.findById(4l).get();
    // 对象导航查询，此客户下的所有联系人
    Set<LinkMan> linkMans = customer.getLinkMans();
    System.out.println(linkMans.size());
}

```

**修改为立即加载：** 不推荐使用
 fetch: 配置关联对象的加载方式：

- EAGER：立即加载

- LAZY：延迟加载
 **tips：** 修改为 EAGER 后，默认查询时就会查询所有数据（left outer join) 不推荐使用。

```
package com.liudezhi.domain;
import lombok.Data;
import lombok.ToString;

@Entity
@Table(name = "cst_customer")
public class Customer {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "cust_id")
    private Long custId;            // 客户主键

    @Column(name = "cust_name")
    private String custName;        // 客户名称

    // 配置客户和联系人之间的关系（一对多关系）
    /**
     * fetch: 配置关联对象的加载方式：
     *  EAGER：立即加载
     *  LAZY：延迟加载
     */
    @OneToMany(mappedBy = "customer", cascade = CascadeType.ALL, fetch = FetchType.LAZY)
    private Set<LinkMan> linkMans = new HashSet<LinkMan>();
}

```

### 2.2. 从多方查询一方

```
/**
 * 从联系人对象导航查询他的所属用户
 *  默认：立即加载
 * 延迟加载：
 *  LinkMan 中 customer 添加 fetch = FetchType.LAZY
 */
@Test
@Transactional
public void testQuery3() {
    LinkMan linkMan = linkManDao.findById(4l).get();
    // 对象导航查询所属的客户
    Customer customer = linkMan.getCustomer();
    System.out.println(customer);
}

```

默认为立即加载：
 如果要修改为延迟加载：
 修改 LinkMan 对象中的 customer

```
@OneToMany(mappedBy = "customer", cascade = CascadeType.ALL)
private Set<LinkMan> linkMans = new HashSet<LinkMan>();

```

## 总结

从一方查询多方：
 默认：使用延迟加载

从多方查询一方
 默认：使用立即加载
