# 新增数据

## 1. 随机生成 id

通过POST请求，可以向一个已经存在的索引库中添加数据。
 **语法：**

```
POST /索引库名/类型名
{
    "key":"value"
}

```

**示例：**

```
POST /test/goods/
{
    "title":"小米手机",
    "images":"http://image.leyou.com/12479122.jpg",
    "price":2699.00
}

```

**响应：**

```

  "_type" : "goods",
  "_id" : "EgvTQ3UBYCgikv9tM58H",

    "total" : 3,
```

## 2. 自定义id

如果我们想要自己新增的时候指定id，可以这么做：

```
POST /索引库名/类型/id值
{
    "key":"value"
}

```

**示例：**

```
POST /test/goods/1
{
    "title":"大米手机",
    "images":"http://image.leyou.com/12479322.jpg",
    "price":2899.00
}

```

**响应：**

```
{
  "_index" : "test",
  "_type" : "goods",
  "_id" : "1",
  "_version" : 1,
  "result" : "created",
  "_shards" : {
    "total" : 3,
    "successful" : 1,
    "failed" : 0
  },
  "_seq_no" : 1,
  "_primary_term" : 1
}

```

**查询：**

```
GET /test/goods/1

```

**响应：**

```
{
  "_index" : "test",
  "_type" : "goods",
  "_id" : "1",
  "_version" : 1,
  "_seq_no" : 1,
  "_primary_term" : 1,
  "found" : true,
  "_source" : {
    "title" : "大米手机",
    "images" : "http://image.leyou.com/12479322.jpg",
    "price" : 2899.0
  }
}

```

## 3. 智能判断

在 Solr 中，新增数据时，只能使用提前配置好映射属性的字段，否则就会报错。

不过在Elasticsearch中并没有这样的规定。

事实上Elasticsearch非常智能，你不需要给索引库设置任何mapping映射，它也可以根据你输入的数据来判断类型，动态添加数据映射。

**eg：**

```
POST /test/goods/3
{
    "title":"超米手机",
    "images":"http://image.leyou.com/12479122.jpg",
    "price":2899.00,
    "stock": 200,
    "saleable":true
}

```

**响应：**

```
{
  "_index" : "test",
  "_type" : "goods",
  "_id" : "3",
  "_version" : 1,
  "result" : "created",
  "_shards" : {
    "total" : 2,
    "successful" : 1,
    "failed" : 0
  },
  "_seq_no" : 0,
  "_primary_term" : 1
}

```

再看下索引库的映射关系:

```
GET /test/_mapping

```

```
{
  "test" : {
    "mappings" : {
      "properties" : {
        "images" : {
          "type" : "keyword",
          "index" : false
        },
        "price" : {
          "type" : "float"
        },
        "saleable" : {
          "type" : "boolean"
        },
        "stock" : {
          "type" : "long"
        },
        "title" : {
          "type" : "text",
          "analyzer" : "ik_max_word"
        }
      }
    }
  }
}

```

stock和saleable都被成功映射了。

**Tips:** 如果存储的是 `String` 类型数据，ES 无智能判断，它就会存入两个字段。例如：
 存入一个 `name` 字段，智能形成两个字段：

- name：text 类型

- name.keyword：keyword 类型
