# Jsoup

我们抓取到页面之后，还需要对页面进行解析。可以使用字符串处理工具解析页面，也可以使用正则表达式，但是这些方法都会带来很大的开发成本，所以我们需要使用一款专门解析 html 页面的技术。

## 1 Jsoup 介绍

Jsoup 是一款 Java 的 HTML 解析器，可以直接解析某个 URL 地址、HTML 文本内容。它提供了一套非常省力的 API，可通过 DOM，CSS 以及类似于 jQuery 的操作方法来去除和操作数据。
 jsoup 的主要功能如下：

1. 从一个 URL，文件或字符串中解析 HTML；

1. 使用 DOM 或 CSS 选择器来查找、取出数据；

1. 可操作 HTML 元素、属性、文本；
 **依赖：**

```
<dependency>
    <groupId>org.jsoup</groupId>
    <artifactId>jsoup</artifactId>
    <version>1.11.3</version>
</dependency>

```

### 2.1 解析 URL

Jsoup 可以直接输入 url，它会发起请求并获取数据，封装为 Document 对象

```
@Test
public void testUrl() throws IOException {
    // 解析 url 地址，第一个参数是访问的 url，第二个参数是访问的超时时间
    Document document = Jsoup.parse(new URL("http://www.baidu.com"), 3000);
    // 使用标签选择器，获取 title 标签中的内容
    String title = document.getElementsByTag("title").first().text();
    System.out.println("title = " + title);
}

```

**PS：** 虽然使用 Jsoup 可以替代 HttpClient 直接发起请求解析数据，但是往往不会这样使用，因为实际的开发过程中，需要使用到多线程、连接池、代理等等方式，而 jsoup 对这些的支持并不是很好，所以我们一般把 jsoup 仅仅作为 html 解析工具使用。

### 2.4 使用 dom 方式遍历文档

#### 2.4.1 元素获取：

1. 根据 id 查询元素 `getElementById`

1. 根据标签获取元素 `getElementByTag`

1. 根据 class 获取元素 `getElementsByClass`

1. 根据属性获取元素 `getElementsByAttribute`

```
@Test
public void testDom() throws IOException {
    // 解析文件
    Document document = Jsoup.parse(new File("C:\\Users\\dezhi\\Desktop\\t.html"), "utf8");

    // 获取元素
    //1. 根据 id 查询元素 `getElementById`
    Element element = document.getElementById("test");
    //2. 根据标签获取元素 `getElementByTag`
    element = document.getElementsByTag("a").first();
    //3. 根据 class 获取元素 `getElementsByClass`
    element = document.getElementsByClass("class_a class_b").first();
    //4. 根据属性获取元素 `getElementsByAttribute`
    element = document.getElementsByAttribute("abc").first();
    element = document.getElementsByAttributeValue("href", "www.anhui.com").first();
    System.out.println("element = " + element.text());
}

```

#### 2.4.2 元素中获取数据：

1. 从元素中获取 id

1. 从元素中获取 className

1. 从元素中获取属性的值 attr

1. 从元素中获取所有属性 attributes

1. 从元素中获取文本内容 text

```
@Test
public void testData() throws IOException {
    // 解析文件
    Document document = Jsoup.parse(new File("C:\\Users\\dezhi\\Desktop\\t.html"), "utf8");
    // 根据 id 获取元素
    Element element = document.getElementById("test");
    String msg = "";
    // 从元素中获取数据
    // 1. 从元素中获取 id
    msg = element.id();
    // 2. 从元素中获取 className
    msg = element.className();
    Set<String> strings = element.classNames();
    /*for (String str : strings) {
        System.out.println("str = " + str);
    }*/
    // 3. 从元素中获取属性的值 attr
    msg = element.attr("class");
    // 4. 从元素中获取所有属性 attributes
    Attributes attributes = element.attributes();
    System.out.println("attributes = " + attributes.toString());
    // 5. 从元素中获取文本内容 text
    msg = element.text();

    System.out.println("msg = " + msg);
}

```

### 2.5 使用选择器概述

**tagname:** 通过标签查找元素，比如：span
 **#id:** 通过 ID 查找元素，比如：#city_bj
 **.class** 通过 class 名称查找元素，比如：.class_a
 **[attribute]:** 利用属性查找元素，比如：[abc]
 **[attr=value]:** 利用属性值来查找元素，比如：[class=s_name]

```
@Test
public void testSelector() throws IOException {
    // 解析文件
    Document document = Jsoup.parse(new File("C:\\Users\\dezhi\\Desktop\\t.html"), "utf8");

    // tagname: 通过标签查找元素，比如：span
    Elements elements = document.select("span");

    //#id: 通过 ID 查找元素，比如：#city_bj
    elements = document.select("#test");
    //.class 通过 class 名称查找元素，比如：.class_a
    elements = document.select(".class_a");
    //[attribute]: 利用属性查找元素，比如：[abc]
    elements = document.select("[abc]");
    // [attr=value]: 利用属性值来查找元素，比如：[class=s_name]
    elements = document.select("[abc=123]");
    for (Element element: elements) {
        System.out.println("element = " + element.text());
    }
}

```

### 2.6 Selector 选择器组合使用

**el#id:** 元素+ID，比如：h3#city_id
 **el.class:** 元素+class，比如：li.class_a
 **el[attr]:** 元素+属性名，比如：span[abc]
 **任意组合:** 比如：span[abc].s_name
 **ancestor child:** 查找某个元素下子元素，比如：city_con li 查找 "city_con" 下的所有 li
 **parent>child:** 查找某个父元素下的直接子元素，比如：.city_con
