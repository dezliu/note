#### maven 标准目录结构

项目分为：

- 核心代码部分

- 配置文件部分

- 测试代码部分

- 测试配置文件

maven 项目标准目录结构

- src/main/java 目录：核心代码部分

- src/main/resources：配置文件部分

- src/test/java 目录：测试代码部分

- src/test/resources：测试配置文件

- src/main/webapp：页面资源，js、css、图片等等

#### maven 常用命令

进入项目所在目录。如：D:\maven\maven-helloworld cmd 打开
 mvn clean：把我们编译好的项目中的信息直接删掉。如果接管别人的项目进行开发，第一件事 mvn clean。删除掉别人本地编译的所有信息，因为每个人的开发环境不一定都是相同的
 mvn compile：编译 src/main/java下的代码，放在了项目目录/target下
 mvn test：编译 src/main/test 下的测试代码及src/main/java 下的代码
 mvn package：打包
 mvn install：不仅执行了compile test package的工作，又做了额外的工作：把包安装到了本地仓库
