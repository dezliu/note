#### maven 生命周期

清除项目编译信息：mvn clean
 编译：mvn compile
 测试：mvn test
 打包：mvn package
 安装：mvn install
 发布：mvn deploy 执行之前必须进行一些配置才可以执行

**发布会执行前面4个（安装，打包，测试，编译）所做的事，安装会执行前面3个所做的事，打包会执行前面两个所做的事，测试会完成编译所做的事，加上测试代码的编译**
