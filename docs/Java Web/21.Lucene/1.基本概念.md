# 什么是全文检索

## 1. 数据的分类

### 1.1. 结构化数据

格式固定、长度固定、数据类型固定。eg：数据库中的数据

### 1.2. 非结构化数据

格式不固定、长度不固定、数据类型不固定。eg：word文档、pdf文档、邮件、html

## 2. 数据的查询

### 2.1. 结构化数据的查询

SQL 语句，查询结构化数据的方法。简单、速度快

### 2.2. 非结构化数据的查询

**eg：** 从文本文件中找出包含某单词的文件。
 1、目测
 2、使用程序把文件读取到内存中，匹配字符串。顺序扫描。
 3、把非结构化数据变成结构化数据

- 先根据空格进行字符串拆分，得到一个单词列表，基于单词列表创建一个索引。

- 查询索引，根据单词和文档的对应的关系找到文档列表。这个过程就叫做**全文检索**。

**tips:** 索引：一个为了提高查询速度，创建某种数据结构的集合。

## 3. 全文检索

先创建索引然后查询索引的过程叫做全文检索。
 索引一次创建可以多次使用。表现为每次查询速度很快。

## 4. 全文检索的应用场景

1. 搜索引擎
 eg：百度、google、sougou

1. 站内搜索
 eg：论坛搜索、微博、文章搜索

1. 电商搜索
 eg：淘宝搜索、京东搜索

只要是有搜索的地方就可以使用全文检索技术。
