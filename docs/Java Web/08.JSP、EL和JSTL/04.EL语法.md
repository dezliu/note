#### EL表达式

1. 概念：Expression Language 表达式语言

1. 作用：替换和简化jsp 页面中java 代码的编写

1. 语法：${表达式}

1. 注意：jsp 默认支持el 表达式。如果要忽略el 表达式：

  1. 设置jsp 中page 指令中：`isELIgnored="true"` 忽略当前jsp 页面中所有的el 表达式

  1. `\${表达式}`：忽略当前这个el 表达式

1. 使用：

  1. 运算

    - 运算符：

      1. 算数运算符：+ - * /(div) %(mod)

      1. 比较运算符：> < >= <= == !=

      1. 逻辑运算符：&&(and) ||(or) !(not)

      1. 空运算符：empty

        - 功能：用于判断字符串、集合、数组对象是否为null，或者长度是否为0

        - `${empty list}`：判断字符串、集合、数组对象是否为null或者长度为0

        - ``${not empty list}`：表示判断字符串、集合、数组对象是否不为null 并且长度 > 0

    - hi

  1. 获取值

    1. el 表达式只能从与对象中获取值

    1. 语法：

      1. ${域名称.键名}：从指定域中获取指定键的值

        - 域名称：

          1. pageScope --> pageContext

          1. requestScope --> request

          1. sessionScope --> session

          1. applicationScope --> application (ServletContext)

        - eg：在request 域中存储了 name=张三 `${requestScope.name}`

      1. {键名}：表示依次从最小的域中查找是否有该键对应的值，知道找到位置。 eg：`{name}`

      1. 获取对象、List集合、Map集合的值

        1. 对象：`${域名称.键名.属性名}`

          - 本质上会去调用对象的getter 方法

        1. List 集合：`${域名称.键名[索引]}`

        1. Map 集合：

          - `${域名称.键名.key名称}`

          - `${域名称.键名["key名称"]}`

  1. 隐式对象：

    - el 表达式中有11 个隐式对象i

    - pageContext：

      - 获取jsp 其他八个内置对象

        - ${pageContext.request.contextPath}：动态

**eg1：el 的基本使用**

```
<%@ page contentType="text/html;charset=utf-8" language="java" %>
<html>
    <head>
        <title>EL</title>
    </head>
    <body>
        ${ 3 > 4 }
        \${ 3 > 4 }
        <hr>
        <h3>算数运算符</h3>
        ${3 + 4}<br>        ${3 / 4}<br data-tomark-pass>        ${3 div 4}<br data-tomark-pass>        ${3 % 4}<br data-tomark-pass>        ${3 mod 4}<br data-tomark-pass>        <h3>比较运算符</h3>
        ${3 == 4}<br data-tomark-pass>        <h3>逻辑运算符</h3>
        ${3 > 4 && 3 < 4}<br data-tomark-pass>        ${3 > 4 and 3 < 4}<br data-tomark-pass>
        <h3>逻辑运算符</h3>
        <%
            String str = "abc";
            request.setAttribute("str", str);

            List list = new ArrayList();
            request.setAttribute("list", list);
        %>
        ${empty str}            <%-- false --%>
        ${not empty str}
        ${not empty list}
    </body>
</html>

```


**eg3：el 获取对象**

```
<%@ page contentType="text/html;charset=utf-8" language="java" %>
<html>
    <head>
        <title>EL</title>
    </head>
    <body>
        <%
            User user = new User();
            user.setName("张三");
            user.setAge(23);
            user.setBirthday(new Date());
            request.setAttribute("u", user);

            List list = new ArrayList();
            list.add("aaa");
            list.add("bbb");
            list.add(user);
            request.setAttribute("list", list);

            Map map = new HashMap();
            map.put("sname", "李四");
            map.put("gender", "男");
            map.put("user", user);
            request.setAttribute("map", map);
        %>
        <h3>el 获取对象中的值</h3>
        ${requestScope.u}
        <%--
            * 通过的是对象的属性来获取
                * setter 或 getter 方法，去掉set / get ，将剩余部分，首字母变小写。
                * setName --> Name --> name
        --%>
        ${requestScope.u.name}<br>        ${requestScope.u.age}<br data-tomark-pass>        ${u.birthday}<br data-tomark-pass>        ${u.birthday.month}<br data-tomark-pass>        ${u.birStr}<br data-tomark-pass>
        <h3>el 获取List 值</h3>
        ${list}<br data-tomark-pass>        ${list[0]}<br data-tomark-pass>        ${list[1]}<br data-tomark-pass>        ${list[1000]}<br data-tomark-pass>       <%-- 如果索引越界，不报错，显示空字符串 --%>
        ${list[2].name}<br data-tomark-pass>
        <h3>el 获取Map 值</h3>
        ${map}<br data-tomark-pass>        ${map.gender}<br data-tomark-pass>        ${map["gender"]}<br data-tomark-pass>        ${map.user.name}<br data-tomark-pass>    </body>
</html>

```
