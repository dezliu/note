## Swagger 配置

可以在项目中创建 SwaggerConfig，进行配置文档内容

### 1. 配置基本信息

Docket：摘要对象，通过对象配置描述文件的信息。
 apiInfo：设置描述文件中 info。参数类型 ApiInfo
 select()：返回 ApiSelectorBuilder 对象，通过对象调用 build() 可以创建 Docket 对象
 ApiInfoBuilder：ApiInfo 构建器

```
@Configuration
public class SwaggerConfig {

    /**
     * 创建 Docket 类型的对象，并使用 Spring 容器管理
     * Docket 是 swagger 中的全局配置对象。
     * @return
     */
    @Bean
    public Docket docket(Environment environment) {

        Profiles profile = Profiles.of("dev", "test");
        boolean flag = environment.acceptsProfiles(profile);

        return new Docket(DocumentationType.OAS_30)
                .enable(flag)   // 利用环境遍历，开发环境swaggerj禁用
                .groupName("Serva")
                .apiInfo(apiInfo()) // 给 docket 上下文配置 api 描述信息
                .select()   // 获取 Docket 中的选择器，返回 ApiSelectorBuilder。构建选择器的。如，扫描什么包的注解
                .apis(RequestHandlerSelectors.withClassAnnotation(RestController.class))    // 规则
                .apis(RequestHandlerSelectors.withMethodAnnotation(NotIncludeSwagger.class).negate())   // 配置什么注解不生成文档。negate 取反
                //.apis(RequestHandlerSelectors.basePackage("com.liudezhi"))  // 设置扫描哪个包（包含子包）
                .paths(PathSelectors.any())
                .build();
    }

    /**
     * API 帮助文档的描述信息
     * @return
     */
    private ApiInfo apiInfo() {
        return new ApiInfoBuilder()
                .title("敏实接口文档")
                .description("this is minshi interface document, you can get all the interface from this document")
                .contact(new Contact("serva",   // 文档发布者名称
                        "www.serva.com",          // 文档发布者网址（企业网站）
                        "liudezhi.iot@outlook.com"     // 文档发布者邮箱
                ))
                .version("1.0")
                .build();
    }
}

```

### 2. 自定义注解设置不需要生成接口文档的方法

#### 2.1. 自定义注解

注解名称随意

```
package com.liudezhi.anno;

/**
 * 自定义注解，用来配置哪些接口不生成接口文档
 */
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface NotIncludeSwagger {
    // 自定义注解中的属性。相当于 @NoIncludeSwagger(value="")
    String value() default "";
}

```

#### 2.2. 添加规则

通过 public ApiSelectorBuilder apis(Predicate<RequestHandler> selector) 可以设置生成规则

```
.apis(RequestHandlerSelectors.withMethodAnnotation(NotIncludeSwagger.class).negate())
// 配置什么注解不生成文档。negate 取反

```

```
@NotIncludeSwagger
@RequestMapping("/req")
public String req(String m) {
    return "req";
}

```

#### 2.3. 设置范围

通过 public ApiSelectorBuilder paths(Predicate<String> selector) 可以设置满足什么样规则的 url 被生成接口文档。可以使用正则表达式进行匹配。
 下面例子中表示只有以 /demo/ 或 /demo1/ 开头的 url 才能被 swagger 生成接口文档。
 如果希望全部扫描，可以使用 `paths(PathSelector.any())`

```
.paths(
    Predicates.or(
        PathSelectors.regex("/demo/.*"),
        PathSelectors.regex("/demo1/.*")
    )
)

```
