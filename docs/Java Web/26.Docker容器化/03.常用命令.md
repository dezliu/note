# 常用命令

## 1. 镜像相关命令

### 1.1. 查看镜像

```
sudo docker images

```

- REPOSITORY: 镜像名称

- TAG: 镜像标签

- IMAGE ID: 镜像 ID

- CREATED: 镜像的创建日期（不是获取该镜像的日期）

- SIZE: 镜像大小
 这些镜像都是存储在 Docker 宿主机的 `/var/lib/docker` 目录下

### 1.2. 搜索镜像

如果需要从网络中查找需要的镜像，可以通过一下命令搜索：

```
docker search 镜像名称

```

- NAME: 仓库名称

- DESCRIPTION: 镜像描述

- STARS: 用户评价，反应一个镜像的受欢迎程度

- OFFICIAL: 是否官方

- AUTOMATED: 自动构建，标识该镜像由 Docker Hub 自动构建流程创建的

### 1.3. 拉取镜像

拉去镜像就是从中央仓库中下载镜像到本地

```
sudo docker pull 镜像名称

```

**eg:** 下载 centos7 镜像

```
sudo docker pull centos:7

```

### 1.4. 删除镜像

按镜像 ID 删除镜像

```
sudo docker rmi 镜像ID

```

删除所有镜像

```
sudo docker rmi `docker images -q`

```

## 2. 容器相关命令

### 2.1. 查看容器

#### 2.1.1. 查看正在运行的容器

```
sudo docker ps

```

#### 2.1.1. 查看所有容器

```
sudo docker ps -a

```

#### 2.1.1. 查看最后一次运行的容器

```
sudo docker ps -l

```

#### 2.1.1. 查看停止的容器

```
sudo docker ps -f status=exited

```

### 2.2. 创建与启动容器

创建容器常用的参数说明：
 创建容器命令：docker run
 -i：表示运行容器
 -t：表示容器启动后会进入其命令行。加入这两个参数后，容器创建就能登录进去。即分配一个伪终端。
