-
基本语法

  1. xml 文档的后缀名 .xml

  1. xml 第一行必须定义为文档声明

  1. xml 文档中有且仅有一个根标签

  1. 属性值必须使用引号引起来(单/双引号都可以)

  1. 标签必须正确关闭

  1. xml 标签名称区分大小写

-
快速入门

```
<?xml version='1.0'?>

<users>
    <user id='1'>
        <name>zhangsan</name>
        <age>23</age>
        <gender>male</gender>
        <br/>
    </user>
    <user id='2'>
        <name>lisi</name>
        <age>20</age>
        <gender>female</gender>
    </user>
</users>
<!-- 使用浏览器打开，不报错代表xml 写对了 -->

```

- 组成部分

1. 文档声明

  1. 格式：<?xml 属性列表 ?>

  1. 属性列表：

    - version：版本号，必须的属性

    - encoding：编码方式。告知解析引擎当前文档使用的字符集，默认值：ISO-8859-1

    - standalone：是否独立

      - yes：不依赖其他文件

      - no：依赖其他文件

1. 指令（了解）：结合CSS

  - <? xml-stylesheet type="text/css" ?>

1. 标签：标签名称自定义的

  - 规则：

    1. 名称可以包含字母、数字以及其他的字符

    1. 名称不能以数字或者标点符号开始

    1. 名称不能以字母 xml （或者 XML、Xml 等等）开始

    1. 名称不能包含空格

1. 属性

  - id 属性值唯一

1. 文本

  - CDATE区：在该区域中的数据会被原样展示（格式：<![CDATE[ 数据 ]]>）

```
<code>
    if(a &lt; b &amp;&amp; a &gt; c) {}

    <![CDATE[
        if(a < b && a > c) {}
    ]]>
</code>

```
