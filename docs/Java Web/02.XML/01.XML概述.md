1. 概念：Extensible Markup Language 可扩展标记语言

- 可扩展：标签都是自定义的。<user><student>

1. 功能

- 存储数据

  1. 配置文件

  1. 在网络中传输

1. xml 与 html 的区别

  1. xml 标签都是自定义的，html 标签是预定义

  1. xml 的语法严格，html 语法松散

  1. xml 是存储数据的，html 是展示数据的
