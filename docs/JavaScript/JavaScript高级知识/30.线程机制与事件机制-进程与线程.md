#### 进程：

- 程序的一次执行，它占有一片独有的内存空间

- 可以通过windows任务管理器查看进程

#### 线程：

- 是进程内的一个独立执行单元

- 是程序执行的一个完整流程

- 是CPU的最小调度单元
