# 11.原型链-属性

- 笔记本：JavaScript高级知识
- 创建时间：2020-01-12 14:07:10 UTC
- 更新时间：2020-01-12 14:19:23 UTC
- 印象笔记 GUID：eaff9f85-b9ff-47bc-b228-300ca04ff374

1. 读取对象的属性值时：会自动到原型链中查找

1. 设置对象的属性值时：不会查找原型链，如果当前对象中没有此属性，直接添加此属性并设置其值

1. 方法一般定义在原型中，属性一般通过构造函数定义在对象本身上

```
function Fun() {

}
Fun.prototype.a = 'xxx';
var fun1 = new Fun();
console.log(fun1.a, fun1);

var fun2 = new Fun();
fun2.a = 'yyy';     // fn2 中没有a 属性，不会去原型链查找，直接添加 a 属性
console.log(fun1.a, fun2.a, fun2);            // xxx yyy

function Person(name, age) {
    this.name = name;
    this.age = age;
}
Person.prototype.setName = function(name) {
    this.name = name;
}
var p1 = new Person('Tom', 12);
p1.setName('Jack');
console.log(p1.name, p1.age);           // Jack 12

var p2 = new Person('Bob', 12);
p2.setName('Cat');
console.log(p2.name, p2.age);           // Jack 12

console.log(p1.__proto__ === p2.__proto__);     // true， 实例对象的隐式原型都指向 构造函数（Person）的显式原型

```
