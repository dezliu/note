#### 1. 什么是回调函数

- 你定义的

- 你没有调用

- 但最终它执行了

#### 2. 常见的回调函数

- dom 事件回调函数

- 定时器回调函数

- ajax 请求回调函数

- 生命周期回调函数

**eg：**

```
<button id="btn">测试点击事件</button>

<script>
    documnt.getElementById('btn').onclick = function() {    // dom 事件回调函数
        alert(this.innerHTML);
    }

    // 定时器(超时、循环定时器)
    setTimeout(function() {     // 定时器回调函数
        alert("到点了");
    }, 2000);
</script>

```
