## 简介

你好，世界！本站使用 [MkDocs](https://www.mkdocs.org/) 与 [Terminal for MkDocs](https://github.com/ntno/mkdocs-terminal) 构建。

## 示例

!!! tip "提示"
    在 `docs/` 目录下新增 Markdown 文件，并在 `mkdocs.yml` 的 `nav` 中注册，即可出现在导航中。

```python
def hello():
    print("Hello, World!")

hello()
```
